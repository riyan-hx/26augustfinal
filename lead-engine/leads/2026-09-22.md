## What the search actually taught us

Three queries were run. Two failed, and the failures are the useful part:

| Query | Result |
|---|---|
| `looking for a UI UX designer` | Recruiters hiring **salaried** designers. Wrong buyer. |
| `need a UI UX designer` | Designers advertising **themselves** — the phrase is in their own sales copy. |
| `"looking for a freelance UI UX designer"` | **Real project briefs.** |

The discriminator is the word **freelance** inside an exact-phrase match. It
excludes salaried job posts, and exact-phrase quoting excludes designer
self-promo, because self-promo says "Need a designer? DM me" and never "looking
for a freelance UI UX designer."

Drop `hiring` from queries entirely. It pulls full-time onsite roles.

**The query to keep using:**

```
https://www.linkedin.com/search/results/content/?keywords=%22looking%20for%20a%20freelance%20UI%20UX%20designer%22%20OR%20%22looking%20for%20a%20freelance%20product%20designer%22%20OR%20%22need%20a%20freelance%20UI%2FUX%20designer%22&datePosted=%5B%22past-week%22%5D&sortBy=%22date_posted%22
```
