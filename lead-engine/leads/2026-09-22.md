## What the search actually taught us

Three queries were run. Two failed, and the failures are the useful part:

| Query | Result |
|---|---|
| `looking for a UI UX designer` | Recruiters hiring **salaried** designers. Wrong buyer. |
| `need a UI UX designer` | Designers advertising **themselves** — the phrase is in their own sales copy. |
| `"looking for a freelance UI UX designer"` | **Real project briefs.** |

The discriminator is the word **freelance** inside an exact-phrase match. It
excludes salaried job posts, and exact-phrase quoting excludes designer
self-promo, because self-promo says "Need a designer? DM me" and never "looking
for a freelance UI UX designer."

Drop `hiring` from queries entirely. It pulls full-time onsite roles.

**The query to keep using:**

```
https://www.linkedin.com/search/results/content/?keywords=%22looking%20for%20a%20freelance%20UI%20UX%20designer%22%20OR%20%22looking%20for%20a%20freelance%20product%20designer%22%20OR%20%22need%20a%20freelance%20UI%2FUX%20designer%22&datePosted=%5B%22past-week%22%5D&sortBy=%22date_posted%22
```

## Queries that failed this round — do not retry these

Added to the two failures already logged above.

| Query | Why it failed |
|---|---|
| `recommend a UI/UX designer` / `anyone know a good UI/UX designer` | Returns recruiters **recommending designers for jobs** — talent referrals, not buyers asking for a referral. Inverted intent. |
| `"send your portfolio to"` / `"share your portfolio at"` | Dominated by recruitment posts for junior graphic and motion designers. The phrase belongs to hiring, not project briefs. |
| Same working query at `past-month` instead of `past-week` | Returned the **same results**. LinkedIn caps content-search results rather than genuinely paging a month, so widening the window adds nothing. |

### Third sweep failures

| Query | Why it failed |
|---|---|
| `"looking for a design partner"` / `"need help with our UI"` | Same inversion as `recommend` — "design partner" is what design **sellers** call themselves. Returned interior architects in Dubai and a student sharing a portfolio. |
| LinkedIn **Jobs** index, `UI/UX Designer` + contract + part-time + remote | The filters do not hold. 47 India results were teachers, video editors and graphic design interns. The contract-design pool on Jobs is thin. |

**Conclusion after nine queries across two indexes:** there is exactly one
reliable pattern — an exact phrase containing **freelance** plus **looking for**.
Everything else inverts (returns designers selling, or recruiters hiring
salaried staff) or returns noise.

Measured yield: **6 usable leads and 3 blocked ones per weekly run.** Widening
the time window does nothing because LinkedIn caps content-search output.
Widening the phrasing does nothing because the adjacent phrases belong to
sellers, not buyers.

**So this lane is quality-capped, not effort-capped.** Grinding more queries is
not the move. Volume has to come from Lane B (OpenOutreach), which is still
waiting on four values in `.env`. Run this search once a week, take the 5-7 good
ones, and stop.
